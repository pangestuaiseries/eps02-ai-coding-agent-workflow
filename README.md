> **Pangestu AI Series** — Official Repository by [@pangesturahmatn](https://instagram.com/pangesturahmatn)

Repository ini memuat panduan transisi dari koding manual gaya lama (copas bolak-balik ChatGPT) menuju era **AI Coding Agent** yang mampu membaca seluruh repositori, membuat file, dan mengeksekusi perintah terminal secara mandiri.

---

## ⚡ Kenapa Copas ChatGPT Itu Ketinggalan Zaman?

| Koding Gaya Lama (Chatbot) | Koding Gaya Modern (AI Coding Agent) |
|---|---|
| Harus copy ratusan baris kode ke browser | Agent langsung membaca struktur folder & seluruh codebase |
| AI tidak tahu dependensi file lain | Agent sadar relasi antar fungsi, package, dan database |
| Hasil koding harus di-copy manual satu per satu | Agent langsung mengedit file dan menyimpan perubahan |
| Tidak bisa menjalankan terminal / testing | Agent bisa menjalankan unit test dan build sendiri |

---

## 🛠️ 3 Tool AI Coding Agent Wajib Dicoba

1. **Claude Code / Cursor**: IDE & CLI agent yang memiliki pemahaman arsitektur proyek kelas dunia.
2. **Antigravity / Gemini CLI**: Agent berbasis sistem agentic dengan kapabilitas multi-tooling dan subagents.
3. **Cline / Roo-Code (VS Code Extension)**: Agent open-source yang terpasang langsung di editor VS Code dengan dukungan aneka model (Claude, DeepSeek, OpenAI).
