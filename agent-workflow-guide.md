# 🚀 Alur Kerja Koding 10x Lebih Cepat Pakai AI Coding Agent

Berikut adalah protokol 4-tahap yang digunakan engineer profesional saat mendelegasikan tugas ke AI Agent:

### Tahap 1: Eksplorasi (Read-First)
Jangan langsung minta koding! Minta agent membaca dan memahami struktur terlebih dahulu.
> *"Baca file `package.json` dan folder `src/components/`, lalu jelaskan konvensi styling dan state management yang digunakan di proyek ini."*

### Tahap 2: Buat Rencana (Spec & Plan)
Minta agent menyusun rencana arsitektur sebelum menyentuh file.
> *"Saya ingin menambahkan fitur ekspor laporan ke format PDF. Buat rencana modifikasi file dan daftar library yang dibutuhkan tanpa menulis kode implementasi dulu."*

### Tahap 3: Eksekusi Terarah (Tackle Step-by-Step)
Instruksikan agent mengeksekusi rencana per langkah.
> *"Setujui rencana poin 1. Buat helper fungsi format angka di `src/utils/formatters.ts`."*

### Tahap 4: Verifikasi & Test
Minta agent mengecek build dan error compiler.
> *"Jalankan perintah `npm run build` di terminal dan pastikan tidak ada error TypeScript."*
